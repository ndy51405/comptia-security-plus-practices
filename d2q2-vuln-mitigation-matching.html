Answer Key & Explanation
Exam Tip: Security+ distinguishes direct mitigations from compensating controls. A WAF can block SQLi but doesn't fix the root cause — parameterized queries do. Input validation alone doesn't prevent CSRF (the request itself is legitimate). Know the OWASP Top 10 primary mitigations: parameterized queries (SQLi), output encoding + CSP (XSS), SameSite + CSRF tokens (CSRF), outbound allowlists (SSRF), and memory-safe constructs + ASLR (buffer overflow).
