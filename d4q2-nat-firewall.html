Key concept: NAPT (also called PAT — Port Address Translation) allows multiple private hosts to share a single public IP by assigning unique ephemeral port numbers on the outside interface. The server only ever sees the firewall's public IP (203.0.113.50); the original private IPs are hidden. This is why NAPT provides implicit topology hiding as a security benefit.
